免费 AI 大模型 API 推荐

最后更新 2026-10-05

推荐一些完全免费且足够用于 AI 总结的大模型 API。这里用最不废话、不绕弯子、最简单直接的话告诉你怎么使用。

🥇 Agnes

Agnes 算是目前能稳定无限 token 使用最聪明一档的免费大模型 API 了

注册并登录 Agnes AI 控制台，进入 API Key 管理页面，创建新的密钥后复制：https://platform.agnes-ai.com/

扩展里面的 Base URL 一栏填写：https://apihub.agnes-ai.com/v1

API Key 填你刚刚复制的，模型名则填写：agnes-2.5-flash或者agnes-3.0-flash

免费用户限制每分钟最大请求次数 20 次，对于本扩展的 AI 总结使用场景完全够用

其中 agnes-2.5-flash 永久免费，agnes-3.0-flash 目前 2026 年 10 月 3 日仍属于限时免费中。后续 agnes-3.0-flash 是否转为收费，或者官方是否又有新的免费模型更新，请以官方最新文档为准：https://www.agnes-ai.com/zh-Hans/docs/

🥇 Ollama

提供 120b 甚至 550b 参数量的免费大模型 API，并且输出速度还相当不错。官方没有明确的 token 用量说明，不过现在是每月刷新免费用量，注册后不强制填写支付信息，所以不用担心超量扣费问题

用邮箱、Github、Google 账号注册并登录 Ollama 控制台，进入 Keys 管理页面，创建新的密钥后复制：https://ollama.com/search?c=cloud

然后如今可以在 Usage 页面看到直接看到支持免费使用的模型，2026 年 10 月 3 日目前有 gpt-oss:120b、nemotron-3-ultra 等模型

但使用时候需要特别注意。点进末尾带 ：参数量的模型，以 gpt-oss:120b 为例，需要去浏览器地址栏删除 :120b 后进入具体模型界面，往下翻才能找到正确的可调用模型名，比如这个模型想要通过 API 调用需要填写 gpt-oss:120b-cloud

末尾不带 ：参数量的模型没有这个问题，比如 256K 上下文 550b 参数量的 nemotron-3-ultra 点进去之后往下翻就能复制到它的实际可调用模型名 nemotron-3-ultra:cloud

扩展里面的 Base URL 一栏填写：https://ollama.com/v1

API Key 填你刚刚复制的，模型名推荐填写：nemotron-3-ultra:cloud 或者 gpt-oss:120b-cloud

🥇 魔搭社区 ModelScope

目前 2026 年 10 月 3 日，魔搭社区已改版为「魔粒」体系，每日免费赠送 250 魔粒，不同模型消耗量不同，选择轻量模型可以完全实现每日免费 AI 总结

缺点是使用较麻烦，既要完成魔搭社区账号注册，又要完成阿里云账号绑定＋实名认证

这里默认你已经完成上面两步之后，打开魔搭社区的访问令牌后台，创建一个仅读权限的 API Key 即可：https://modelscope.cn/my/settings/token

这里没有具体真实可用的模型，因为可用模型一直在变动。需要自行筛选支持推理 API-Inference 的文本模型

然后具体调用的模型名，以点进模型之后，点击复制按钮获取到的为准

扩展里面的 Base URL 一栏填写：https://api-inference.modelscope.cn/v1

API Key 填你刚刚复制的，模型名推荐填写：MiniMax/MiniMax-M1-80k或 inclusionAI/Ling-3.0-flash 或 mistralai/Mistral-Large-Instruct-2407

以上模型为 2026 年 10 月 3 日实际测试可用，MiniMax-M1-80k 为原生 1M 百万上下文的 456B 参数模型，Ling-3.0-flash 为原生 256K 上下文的 124B 参数模型，Mistral-Large-Instruct-2407 为 128K 上下文的 123B 参数模型

🥈 硅基流动

硅基流动提供了一些 10B 以下参数模型可以无限 token 免费使用

注册之后点击左侧的 API 密钥页面，创建新的密钥后复制：https://cloud.siliconflow.cn/

然后来到模型广场，点击筛选器，筛选 10B 以下的对话模型

这里强调一下，10B 以下存在完全免费的模型 ≠ 10B 以下模型都完全免费

就比如 GLM-4-9B 完全免费，但 Qwen3.5-9B 仍旧是收费的。所以具体调用时候请自行看清楚价格

最后配置时，扩展里面的 Base URL 一栏填写：https://api.siliconflow.cn/v1/

API Key 填你刚刚复制的，模型名推荐填写：deepseek-ai/DeepSeek-R1-0528-Qwen3-8B

🥈 智谱 BigModel

智谱提供了一些模型可以无限 token，永久免费使用，缺点就是实际可用模型参数量较低，智力比较落后

注册并登录 BigModel 官网之后，点击页面右上角进入控制台，然后找到页面左侧目录的 API Key，新建 API Key 并复制：https://www.bigmodel.cn

扩展里面的 Base URL 一栏填写：https://open.bigmodel.cn/api/paas/v4

API Key 填你刚刚复制的，模型名推荐填写：GLM-4-Flash-250414

注：智谱 BigModel 上的 30B 参数 200K 的 GLM-4.7-Flash 虽然永久免费能力挺好，但是调用人数太多，实际使用几乎都会超时无法使用。GLM-4-Flash-250414 具备 128K 上下文在文本总结这个场景还是可以用一用的。未来是否会有更多免费模型，请参看官方 API 计费文档：https://docs.bigmodel.cn/cn/guide/start/pricing

🥈 小红书

注册并登录 Dots API 开放平台，进入 API Key 管理页面，创建新的 API Key 之后复制：https://dots.ai/platform/

扩展里面的 Base URL 一栏填写：https://note3-prev-api.askdiandian.com/v1

API Key 填你刚刚复制的，模型名则填写：dots3-note-prev

目前 2026 年 10 月 3 日，dots3-note-prev模型仍属于限时免费中，具体什么时候恢复收费请以官方最新文档为准：https://dots.ai/platform/docs

🥈 书生

每月送 9000 万 Token（输入 9000 万，输出 9000 万），对于低频使用场景还是够用的，但建议是随时登录后台关注一下免费额度余量

使用方法为注册并登录书生 AI 控制台，进入获取个人密钥管理页面，创建新的密钥后复制：https://internlm.intern-ai.org.cn/api/tokens

扩展里面的 Base URL 一栏填写：https://chat.intern-ai.org.cn/api/v1

API Key 填你刚刚复制的，模型名推荐填写：intern-latest

intern-latest 会默认指向他们最新发布的 Intern 系列模型，当前是 256K 上下文的 intern-s2

更多可用模型请查看官方文档：https://internlm.intern-ai.org.cn/api/document

🥉 百灵

原百灵平台提供每日免费 50 万 token，现改版之后是每月 1 号向使用者提供价值 10 元的 Token 抵用券。如果你 AI 总结的用量不大，也是可以用一下这个 API

此为 2026 年 10 月 3 日信息，具体最新政策请以官方最新文档为准：https://developer.ant-ling.com/zh-CN/docs/getting-started/changelog/billing-upgrade/

使用方法为注册并登录百灵计费平台，进入 API Key 管理页面，创建新的 API Key 之后复制：https://chat.ant-ling.com/platform/account

扩展里面的 Base URL 一栏填写：https://api.ant-ling.com/v1

API Key 填你刚刚复制的，模型推荐使用定价更低的：Ling-3.0-flash

Firefox 扩展使用说明与安装指南

更新日期 2026-10-14

由于三番五次在 Firefox 商店尝试上架，都被审核员强制停用。甚至平台对我的开发者账号也进行了封号处理，禁止我再提交另外的扩展，所以抱歉无法提供直接的 Firefox 附加组件安装链接

同时由于 Firefox 正式版浏览器只认经过商店签名的扩展，无法直接通过本地加载方式安装

所以通过 Chromium 内核浏览器来使用本扩展是最简单的办法（Chrome、Edge 等常见浏览器）

更换 Firefox 版本

如果是实在是需要在 Firefox 上使用本扩展，可以通过更换 Developer Edition／ESR／Nightly 版本的 Firefox 来实现

Firefox ESR

  • 官网下载地址（选择 ESR 延长支持版，支持 Windows／Mac／Linux）：https://www.mozilla.org/firefox/enterprise/#download
  • 便携版（仅支持 Windows）：https://portableapps.com/apps/internet/firefox-portable-esr

Firefox Developer Edition

  • 官网下载地址：https://www.mozilla.org/firefox/developer/

Firefox Nightly

  • 官网下载地址：https://www.mozilla.org/firefox/channel/desktop/#nightly

装好后的操作

以下步骤适用于上述 3 款浏览器

安装好浏览器之后在浏览器地址栏输入 about:config 后回车，对于弹出的风险提示选择「接受风险并继续」

然后再在搜索框输入 xpinstall.signatures.required，点击 ⇌ 按钮，把值从 true 改成 false

然后大概率你需要去浏览器地址栏输入 about:preferences#languages，找到 Languages 设置来把浏览器语言改为中文

然后我们点击这里下载 Firefox 版本扩展的本地安装包：夸克网盘、百度网盘

最后的安装就很简单了：

  • 方法 A：直接把扩展的 xpi 文件拖进 Firefox 窗口 ➔ 弹出的安装框点击「添加」即可
  • 方法 B：地址栏输入 about:addons 后回车访问 ➔ 右上齿轮 ➔ 从文件安装附加组件 ➔ 选择本地的扩展 xpi 文件

最后就可以在 Firefox 中正常使用扩展了

Chrome 扩展下载与本地安装教程

更新日期 2026-10-21

如果你无法打开 Chrome 扩展程序商店，可以通过下载 crx 扩展文件，以本地加载方式来安装扩展。

下载 crx 安装包

首先下载 crx 扩展安装包文件：下载地址 ¹ 、下载地址 ²、下载地址 ³（三个链接任选其一即可）。

打开扩展程序页面

然后打开 Google Chrome 浏览器，点击右上角的 🧩 按钮，进入扩展程序页面

开启开发者模式

将右上角「开发者模式」的开关打开

拖拽安装

把刚刚下载的虚空搜索 crx 扩展文件拖入浏览器的扩展程序页面，在弹出的窗口点「添加扩展程序」，就能安装成功了！
